# Cybersecurity & Systems Engineering Notes

Welcome to my technical knowledge base! I am currently executing an intensive, closed-book training roadmap toward becoming job-ready for **Junior Penetration Testing / AppSec** and **Tier 1 SOC Analyst** roles by **March 2027**.

Rather than relying on passive tutorials or walkthroughs, I document core operating system mechanics, networking protocols, and offensive/defensive security principles in my own words after completing hands-on labs on [pwn.college](https://pwn.college/dojos).
